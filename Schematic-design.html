System Schematic Design

This page documents my system schematic layout. My system is the human interface, so the main components are off-board potetiometers connected to ADCs via 3-pin headers. The voltage regulation circuit is included at the bottom of the schematic and connects to to the controller, well as the ADCs and potentiometers. A 5-pin header is included to allow for the controller to be programed via ICSP. There are 8-pin connectors included to be used for UART communication between systems. Additionally, there are 4 2-pin headers available for debugging.
My schematic design meets the requirements of my system presented by the project. My system needs to do three main tasks; it needs be powered from a 9V barrel jack, read the off-board potentiometer outputs, and send those readings to the other systems. This schematic performs these tasks using the voltage regulator circuit, have the ADCs connected to 3-pin headers where off-board potentiometers can be connected, and including a pair of 8-pin headers for UART communication to other systems.
